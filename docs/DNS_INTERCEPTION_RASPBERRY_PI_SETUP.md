# DNS Interception - DEPRECATED

## ⚠️ Important Notice

**This feature has been removed from the system.** DNS interception is no longer used. The system now only intercepts HTTP requests.

## Current System

The system now only intercepts HTTP requests. HTTPS requests are not intercepted.

- **HTTP Requests**: ✅ Intercepted and redirected to portal
- **HTTPS Requests**: ❌ Not intercepted

## No Setup Required

No DNS interception setup is needed. The system works with HTTP-only interception using NoDogSplash.

For complete setup instructions, see `docs/NODOGSPLASH_SETUP.md`.
