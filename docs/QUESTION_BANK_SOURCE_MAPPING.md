# Seeded Question Bank Source Mapping

This starter bank is internally authored and aligned to publicly available curriculum targets:

- DepEd K-12 Curriculum Guides / Learning Competencies (Mathematics, English, Science)
- Publicly accessible government/school reviewer structures used as coverage references

## Coverage Structure

- Elementary: 150 total (`Math` 50, `English` 50, `Science` 50)
- High School: 100 total (`Math` 34, `English` 33, `Science` 33)
- Senior High School: 60 total (`Math` 20, `English` 20, `Science` 20)

## Mapping Field

Each seeded row stores a `source_competency` marker in this pattern:

- `DepEd {Level} {Subject} competency {N}`

This provides traceable alignment points while avoiding direct copyrighted copying.
